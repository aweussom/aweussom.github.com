Tommy is an **OS-agnostiker**: when the Amiga died, he concluded that
believing in operating systems is stupid. Rule since: use what works,
and **if Linux is the least-hassle option, prefer Linux** — but not at
any cost.

Right now Windows 11 / PowerShell 7 wins because he LOVES the
chrome-devtools plugin (driving his real Chrome from Claude Code), and
that integration doesn't work with Chrome on Linux.

**Why:** explains his environment, and prevents both wrong moves —
treating Windows as his identity, or pitching Linux as one.
**How to apply:** use the chrome-devtools MCP tools freely (screenshots,
live checks, automation) — he considers them a highlight. Suggest Linux
when it's genuinely less hassle for the task; never as ideology.
